# AI Extract - AI 多文件代码提取与工作流工具

从剪贴板读取 AI 输出的代码片段，自动解析出多个文件并保存到指定目录，同时支持 Git 和 Zip 备份。  
内置提示词链工具，可逐步构建复杂需求并生成符合工具格式的提示词，直接复制给 AI。  
支持 `###FILE`、`###READ`、`###DELETE` 三种指令，实现完整的文件创建、读取和删除工作流。

## 功能

- 📋 自动读取系统剪贴板中的结构化代码
- 📁 `###FILE`批量创建文件，自动处理嵌套目录
- ⚠️ 启发式空函数/空类警告（C/C++/Python/JS 等）
- 🔒 路径安全检查（拒绝 `..` 和绝对路径）
- 💾 文件保存前预览、确认（交互模式）
- 🔄 自动模式、循环模式、提示词链模式
- 🗃️ 自动 Git 初始化和提交（备份）
- 📦 自动 Zip 压缩备份
- 🔍 `###READ` 指令：读取本地文件内容（或路径）并复制到剪贴板，方便发给 AI
- 🗑️ `###DELETE` 指令：删除指定的文件（需两次确认）
- 💬 提示词链工具：逐步添加需求，生成包含格式要求的完整提示词，并自动复制到剪贴板
- ⚙️ 配置文件（`ai-extract.ini`）：保存窗口位置、启动目录、默认模式、备份策略等
- 🌐 中英双语彩色终端输出

## 构建

### Windows (MinGW-w64)
```cmd
g++ -std=c++17 -o ai-extract.exe ai-extract.cpp -luser32
```

### Linux
```bash
g++ -std=c++17 -o ai-extract ai-extract.cpp -lstdc++fs
```

### macOS
```bash
clang++ -std=c++17 -o ai-extract ai-extract.cpp
```

## 快速开始

1. 将 AI 生成的符合格式的文本复制到剪贴板。
2. 双击 `ai-extract.exe` 或从命令行运行 `ai-extract`。
3. 按回车读取剪贴板，程序会显示即将创建/读取/删除的文件列表。
4. 确认操作后，文件将直接生成在当前工作目录（或通过 `-o` 指定的目录）。
5. 完成后可继续处理下一个剪贴板内容，或输入命令进入提示词链模式。

### 命令行参数

```
用法: ai-extract [选项]
  -o <dir>       输出目录 (默认: . 即当前目录)
  -f             强制覆盖已有文件
  -i <file>      从文本文件读取输入，而不是剪贴板
  --no-backup    跳过 Git 和 Zip 备份
  --debug        调试模式：打印剪贴板原文等详细信息
  --auto         自动模式：启动后立即处理剪贴板（无交互确认）
  --loop         强制进入循环交互模式
  -h, --help     显示帮助信息
```

## 剪贴板输入格式（指令语法）

所有指令都以 `###` 开头，后跟指令类型、冒号、一个空格和相对路径。  
指令类型有：`FILE`、`READ`、`DELETE`。  
指令之间用空行或新指令头分隔。

### FILE 指令（创建/覆盖文件）

```
###FILE: 相对路径/文件名
文件内容（支持多行）
```

- 如果文件内容被三反引号 `` ``` `` 包裹，程序会自动剥离它们及其语言标识符。
- 路径使用正斜杠 `/`，相对于输出目录。
- 路径不能包含 `..` 或绝对路径（以 `/` 开头），否则会跳过并显示警告。

**示例：**
```
###FILE: src/main.cpp
#include <iostream>
int main() {
    std::cout << "Hello";
    return 0;
}

###FILE: README.md
# My Project
This is a test.
```

### READ 指令（读取文件到剪贴板）

```
###READ: 相对路径/文件名
```

- 程序会读取该文件的内容（或根据配置复制文件路径），然后**自动复制到剪贴板**，方便你粘贴给 AI。
- 通常与 `FILE` 指令一起使用，先创建文件，再读取其内容发送给 AI 进行下一步修改。

**示例：**
```
###READ: src/main.cpp
```

读取模式可在 `ai-extract.ini` 中配置：
- `file_read_mode=text`（默认）：复制文件完整内容到剪贴板。
- `file_read_mode=path`：仅复制文件的绝对路径到剪贴板（适合大文件或二进制文件）。

### DELETE 指令（删除文件）

```
###DELETE: 相对路径/文件名
```

- 程序会列出要删除的文件，并要求**两次确认**（每次输入 `y`），避免误删。
- 两次确认都通过后，才会执行删除操作。

**示例：**
```
###DELETE: old_deprecated.cpp
```

### 混合使用示例

将以下内容复制到剪贴板，程序会创建 3 个文件，读取其中一个文件内容，并删除一个临时文件：

```
###FILE: src/main.cpp
#include "utils.h"
int main() { return 0; }

###FILE: src/utils.h
#pragma once
void helper();

###FILE: src/utils.cpp
#include "utils.h"
void helper() {}

###READ: src/main.cpp
###DELETE: temp.txt
```

## 空函数/空实现检测

程序会对以下语言的文件进行简单的启发式检测，发现可能偷懒的空实现：

- C/C++/Java/C#：函数体为 `{ }` 或 `{ return; }` 等。
- Python：函数体内只含有 `pass`、`...` 或空白。
- JavaScript/TypeScript：函数体为 `{}` 或 `{ return; }`。

检测到空实现后会显示文件、行号和描述，但不会阻止文件创建。

## 提示词链模式

在交互模式下输入 `:prompt` 进入提示词链模式。  
你可以逐步追加需求，最后生成一个包含**固定格式要求**的完整提示词，并自动复制到剪贴板。

**提示词模板会自动追加以下内容：**
```
你是一个严格的代码生成助手。请根据以下需求，生成对应的项目文件。
【重要】输出必须且仅包含以下格式的内容，不能有任何额外解释、对话或 Markdown 说明：

###FILE: 相对路径/文件名
文件完整内容（代码、文本等）
...
```

**提示词链命令（在提示词模式下输入）：**
- `:help` – 显示帮助
- `:history` – 查看已输入的所有需求
- `:undo` – 撤销最后一条需求
- `:reset` – 清空所有需求
- `:generate` – 生成完整提示词并复制到剪贴板
- `:quit` 或 `:exit` – 退出提示词模式（需求历史会保留，下次进入可继续）

**使用流程：**
1. 输入 `:prompt` 进入。
2. 逐条输入需求，每条一行。
3. 输入 `:generate` 生成提示词并复制。
4. 将剪贴板内容粘贴给 ChatGPT 等 AI 工具。
5. 将 AI 的回复复制回剪贴板。
6. 回到主界面按回车提取文件。

## 配置文件（ai-extract.ini）

程序启动时会读取同目录下的 `ai-extract.ini`，可配置以下项（缺省值见注释）：

```ini
# 默认模式：auto（自动）/ loop（循环）/ interactive（交互）
default_mode=interactive

# 输出目录（文件/读取/删除均基于此目录）
output_dir=.

# 启动后自动切换的工作目录
startup_working_dir=D:\projects

# 是否强制覆盖已存在的文件
force=false

# 是否开启调试输出
debug=false

# 是否跳过备份
no_backup=false

# 读取模式：text（复制内容）/ path（复制路径）
file_read_mode=text
```

如果文件不存在，程序会使用内置默认值。

## 备份

每次成功创建文件后（除非使用 `--no-backup`），程序会在**输出目录**执行：

1. **Git 备份**：如果 `.git` 目录不存在则自动 `git init`，然后 `git add -A` 并提交（提交信息包含时间戳）。
2. **Zip 备份**：在输出目录的父目录生成一个时间戳命名的 zip 压缩包。

备份失败不会中断程序，仅显示警告。

## 运行时命令（主界面）

在交互模式下，除了直接按回车读取剪贴板，还能输入以下命令：

- `:help` – 显示命令列表
- `:dir [路径]` – 显示或切换工作目录
- `:out <目录>` – 设置输出目录
- `:force [on|off]` – 切换强制覆盖
- `:debug [on|off]` – 切换调试模式
- `:backup [on|off]` – 切换备份开关
- `:auto` – 立即读取剪贴板并自动处理（无确认）
- `:prompt` – 进入提示词链模式
- `:quit` – 退出程序

## 注意事项

- Windows 下剪贴板读取使用 Win32 API，支持 UTF-8 文本。
- 确保复制的 AI 输出采用纯文本格式（可从记事本中转）。
- 文件路径中请使用正斜杠 `/`，程序会自动转换为 Windows 的反斜杠。
- 绝对路径和包含 `..` 的路径会被拒绝，以防止意外覆盖系统文件。
