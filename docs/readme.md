# ai-extract

AI 多文件代码提取与自动化工作流工具。

从剪贴板读取结构化指令，执行文件创建、读取、删除、命令运行和网页浏览，并自动备份。内置提示词链辅助生成符合格式的 AI 提示，支持多轮任务管理与上下文自动更新。

## 功能

- 📋 从系统剪贴板读取 AI 输出的指令序列
- 📁 依据 `###FILE` 创建多文件，自动处理嵌套目录
- ⚠️ 空函数/空实现检测（C/C++/Java/C#/Python/JS/TS）
- 🔒 路径安全检查（拒绝 `..` 和绝对路径）
- 🔄 交互模式、自动模式、循环模式、简易模式
- 🗃️ 自动 Git 初始化并提交（输出目录内）
- 📦 自动 Zip 压缩备份
- 💬 提示词链模式：逐步构建需求，生成含格式约束的完整提示词并复制到剪贴板
- 🌳 项目文件树展示（`:tree`），可视化输出并复制到剪贴板
- 📂 一键打开输出文件夹（`:open`，Windows）
- 🌐 网页纯文本抓取浏览（`:browse`、`###BROWSE` 指令）
- 🖥️ 运行时命令切换配置（工作目录、输出目录、强制覆盖等）
- ⚙️ 持久化配置文件 `ai-extract.ini`（启动目录、默认模式、备份策略等）
- 🎨 彩色终端输出（信息/成功/警告/错误/输入）
- 🧭 简易模式（方向键菜单），无需记忆命令即可完成常见操作
- 🧩 任务管理系统：支持任务创建、启动、暂停、状态查看，AI 自动更新状态块（STATE_BLOCK），自动备份上下文，记录全局记忆
- 🔁 下一轮对话快捷操作（`:next`），自动合并项目上下文与活动上下文到剪贴板

## 指令语法

工具通过剪贴板接收以下指令，必须严格格式。整个输入只能是这些指令的组合，不可夹杂其他文字。

### 1. 创建/更新文件
```
###FILE: 相对路径/文件名
文件完整内容（多行）
```
- 路径使用正斜杠 `/`，相对于输出目录。
- 若文件内容被三反引号包裹，工具会自动剥离。
- 路径包含 `..` 或以 `/` 开头的绝对路径会被拒绝。

### 2. 读取文件到剪贴板
```
###READ: 相对路径/文件名
```
- 将文件内容（或路径，根据配置）复制到剪贴板，便于传给 AI。

### 3. 删除文件
```
###DELETE: 相对路径/文件名
```
- 需要用户两次确认后执行删除，防止误删。

### 4. 执行命令
```
###EXEC:
命令行指令
```
- `###EXEC:` 后换行书写完整命令行（可含 `&&` 串联多条命令）。
- 工具将执行该命令，将标准输出和错误合并后复制到剪贴板。
- 建议将 `###EXEC` 放在 `###FILE` 之后，确保文件已存在。

### 5. 浏览网页
```
###BROWSE: URL
```
- 抓取指定网页的纯文本内容并复制到剪贴板，支持 HTTP/HTTPS。
- 若 URL 为空，程序会发出警告并跳过。
- 注意：受网站反爬策略影响，部分页面可能返回错误，错误信息会详细显示。

### 6. 任务状态更新（STATE_BLOCK）

AI 在处理已有项目的每一轮代码输出后，必须附加以下状态块，用于工具自动更新任务进度与记忆：

```
### STATE_BLOCK
STEP: <当前步数，从1递增>
CURRENT_SUBTASK: <当前正在执行的子任务名称>
OUTCOME: <本轮完成情况简述>
FACTS: <从本轮中学到的重要事实，用 | 分隔多条>
NEXT: <下一轮需要执行的子任务，或 TASK_COMPLETE / ABANDON>
### END_STATE
```

- 该块不会被当作文件操作，工具会自动解析并更新 `.ai-extract/active_context.md` 和全局记忆日志。
- 每轮对话必须包含此块（首轮任务启动除外）。

## 命令行参数

```
用法: ai-extract [选项]
  -o <dir>       输出目录 (默认: . 即当前目录)
  -f             强制覆盖已有文件（默认询问）
  -i <file>      从文本文件读取指令（而非剪贴板）
  --no-backup    跳过 Git 和 Zip 备份
  --debug        调试模式：打印剪贴板原文等详细信息
  --auto         自动模式：立即读取剪贴板并执行（无确认）
  --loop         强制进入循环交互模式
  --task <cmd>   任务管理 (init / start <id> / stop / status)
  -h, --help     显示帮助
```

## 运行时命令（普通交互模式）

在交互模式下，可以输入以下命令：

| 命令 | 说明 |
|------|------|
| `:help` | 显示命令列表（渲染 README.md） |
| `:dir [路径]` | 显示当前工作目录，或切换到指定路径 |
| `:out <目录>` | 设置输出目录（立即生效） |
| `:force [on/off]` | 切换强制覆盖开关 |
| `:debug [on/off]` | 切换调试输出 |
| `:backup [on/off]` | 切换备份开关 |
| `:auto` | 立即读取剪贴板并自动处理（跳过确认） |
| `:prompt` | 进入提示词链模式 |
| `:tree` | 显示输出目录的文件树并复制到剪贴板 |
| `:open` | 用文件资源管理器打开输出目录（Windows） |
| `:browse <url>` | 抓取网页纯文本并复制到剪贴板 |
| `:easy` | 进入简易模式（方向键菜单） |
| `:task init` | 初始化当前项目的任务管理目录（`.ai-extract/`） |
| `:task start <任务ID>` | 启动指定任务，生成上下文并复制到剪贴板 |
| `:task stop` | 暂停当前活动任务 |
| `:task status` | 查看所有任务状态 |
| `:next` | 将项目上下文与活动上下文合并并复制到剪贴板，用于下一轮对话 |
| `:quit` | 退出程序 |

## 简易模式 (`:easy`)

通过方向键和回车操作的图形化菜单，无需记忆语法。主菜单包含：

| 菜单项 | 说明 |
|--------|------|
| **创建文件** | 输入文件名和内容（以 END 结束） |
| **读取文件到剪贴板** | 输入文件名，内容复制到剪贴板 |
| **删除文件** | 输入文件名，经两次确认后删除 |
| **浏览网页** | 输入 URL，纯文本抓取后复制到剪贴板 |
| **执行命令** | 输入命令行指令并执行 |
| **查看项目文件树** | 显示输出目录树结构 |
| **打开输出目录** | 资源管理器打开当前输出目录 |
| **启动新项目（生成提示词）** | 进入提示词链模式，逐步构建需求并生成提示词 |
| **项目任务维护** | 子菜单：开始任务、暂停活动任务、查看任务状态、继续下一轮对话（生成 :next 提示词） |
| **退出简易模式** | 返回普通交互模式 |

在子菜单中，可通过方向键选择任务列表中的具体任务，启动后自动生成上下文提示词并复制到剪贴板。

## 提示词链模式 (`:prompt`)

逐步输入需求，工具会将每一条需求追加到列表，最后生成包含所有需求及严格格式说明的完整提示词，并自动复制到剪贴板。

**提示词链命令：**

| 命令 | 说明 |
|------|------|
| `:help` | 显示帮助 |
| `:history` | 查看已输入的需求列表 |
| `:undo` | 撤销最后一条需求 |
| `:reset` | 清空所有需求 |
| `:tree` | 将当前项目文件树作为一条需求插入 |
| `:generate` | 生成完整提示词（替换模板中的 {{REQUIREMENTS}}）并复制到剪贴板 |
| `:quit` / `:exit` | 退出提示词模式，需求历史保留 |

启动时工具会从可执行文件同目录读取 `prompt_template.md` 作为提示词模板（若不存在则使用内置默认模板），并渲染显示该模板内容。生成提示词时，还会自动附加当前项目的文件树供 AI 参考。

## 任务管理系统

任务管理依赖项目目录下的 `.ai-extract/` 隐藏文件夹，包含以下核心文件：

- `tasks.json` – 任务列表与状态
- `project_context.md` – 项目永久上下文（技术栈、结构、规范、经验）
- `active_context.md` – 当前活动任务的动态上下文
- `context_backups/` – 活动上下文的自动备份

**任务命令（命令行与交互模式通用）：**

| 命令 | 说明 |
|------|------|
| `--task init` / `:task init` | 初始化 `.ai-extract/` 目录及默认文件 |
| `--task start <id>` / `:task start <id>` | 启动指定任务，生成初始活动上下文并复制提示词到剪贴板 |
| `--task stop` / `:task stop` | 暂停当前活动任务 |
| `--task status` / `:task status` | 列出所有任务及状态 |

**工作流：**

1. **新建项目时**：先使用 `:prompt` 生成提示词并发送给 AI，AI 会通过指令创建 `tasks.json`、`project_context.md` 等基础文件。
2. **启动任务**：`--task start <id>` 会生成包含项目上下文和活动上下文的提示词并放入剪贴板，用户发送给 AI 开始执行。
3. **AI 回复后**：将 AI 的回复复制到剪贴板，在交互模式中按回车，工具解析指令并更新活动上下文（STATE_BLOCK 中的事实、进度等）。随后使用 `:next` 命令获取下一轮对话提示词。
4. **简易模式**：在“项目任务维护”菜单中可以图形化完成启动、暂停、查看状态和生成下一轮上下文。

## 配置文件 `ai-extract.ini`

程序运行目录下的 `ai-extract.ini` 会在退出时自动保存（首次运行后生成）。

```ini
# ai-extract configuration
default_mode=interactive   # auto / loop / interactive
output_dir=.               # 文件输出根目录
startup_working_dir=        # 启动后自动切换的目录
force=false                # 是否默认强制覆盖
debug=false                # 是否开启调试模式
no_backup=false            # 是否禁用备份
file_read_mode=text        # 读取文件时复制内容(text)或路径(path)
confirm_exec=false         # 执行 ###EXEC 前是否需要确认
easy_mode=false            # 是否默认进入简易模式
```

## 构建

### Windows (MinGW-w64)
```cmd
g++ -std=c++17 -o output\ai-extract.exe src/main.cpp src/config.cpp src/utils.cpp src/clipboard.cpp src/pathutil.cpp src/parser.cpp src/directiveproc.cpp src/backup.cpp src/promptchain.cpp src/markdown_render.cpp src/task_manager.cpp src/web_browser.cpp src/easy_mode.cpp -luser32 -lshell32
```

### Linux
```bash
g++ -std=c++17 -o ai-extract ai-extract.cpp -lstdc++fs
```

### macOS
```bash
clang++ -std=c++17 -o ai-extract ai-extract.cpp
```

## 典型工作流

1. 复制 AI 助手生成的指令文本到剪贴板。
2. 双击 `ai-extract.exe` 或从命令行运行。
3. 在交互界面按回车，工具解析并展示待执行的操作统计。
4. 确认后，文件被创建/读取/删除，命令被执行，网页被浏览。
5. 完成后可继续处理新剪贴板内容，或使用 `:prompt` 构建新的 AI 请求，或使用任务管理进行多轮维护。

**新项目启动**：使用 `:prompt`（或简易模式中的“启动新项目”）生成提示词，AI 将自动创建项目基础文件。  
**迭代维护**：使用 `:task start` 启动任务，每轮执行后按回车处理指令，随后用 `:next` 获取下一轮上下文。
